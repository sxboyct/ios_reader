# 映夏阅读 · iOS

从 [jo32/tvbox-silicon](https://github.com/jo32/tvbox-silicon) 提取的独立文字阅读应用，支持 iOS 17+ 的 iPhone / iPad。

保留上游 Legado JavaScript 规则引擎、Swift 书源模型、搜索聚合、章节缓存、书架与书签模型、简繁转换。当前版本 1.3.2，主界面只有「书架 / 找书 / 书源」，字体管理和图片背景在阅读设置中。没有影视、直播、音乐、有声书播放、漫画、网盘、广告、远程错误上报，以及 Java / Python / Node 应用运行时。

## 阅读

1. 在「书源」粘贴文字书源地址，或导入 JSON / XBS。支持 Legado 对象/数组以及香色的别名包装对象，文件最大 32 MB；非文字源会过滤。
2. 启用所需书源，在「找书」搜索书名或作者，再选择具体书源。
3. 打开章节后进入独立全屏阅读，默认隐藏主导航、顶部标题栏、状态栏、进度和底部横条。点击页面中间显示菜单，左上角退出。菜单里的「设置」可调整状态栏、横条、进度显示、字号、行距、主题、简繁和字体。
4. 默认跟手平移翻页：右滑下一页、左滑上一页。保留页面跟随手指和松手后的平移动画，距离达到阅读区域宽度的 12%（最多 40 点）即可换页；至少移动 8 点且同向速度达到 450 点/秒的轻快短划也可换页，否则回弹，无需超过半屏。在平移设置中关闭「右滑进入下一页」可改为左滑下一页。点击左右侧仍分别为上一页/下一页。在「设置 → 翻页方式」可选择平移、仿真（系统卷页）、覆盖、渐隐、上下、滚动，开关动画并调整点击区域。系统「减弱动态效果」开启时停用动画。章末继续翻页进入下一章，章首先向前翻进入上一章末页；滚动模式可上下拉越过章界，也可通过菜单切章。
5. 分页按屏幕尺寸、实际字体、字号和行距计算，长段落可跨多页。页码滑块位于阅读菜单。保存章节和文字位置，换字号/横竖屏后重新分页；旧版段落进度与书签继续可读。预读后续章节，已缓存的章节可离线阅读；系统可能清理缓存，这不是永久离线下载功能。

背景和翻页动画覆盖整个屏幕，包括顶部和底部安全区域；只有文字保留 24 点左右边距、14 点上下边距并避开刘海及底部操作区，不再把背景和动画裁成正文大小的矩形。分页前准备当前页及相邻页图像，后续按需更新并最多缓存三页；排版任务放在稳定容器上，避免加载章节后因内容视图切换再次排版。阅读进度写入串行后台队列，退到后台或退出阅读时完成剩余写入。

1.3.2 针对跨章后翻第二页卡顿和内容不全调整了阅读渲染管线，而不是增加下载缓存：分页采用 CoreText 实际可见字符范围，并保存同一份绘制帧，避免分页后绘制再次改变页边界。简繁转换、整章分页和分页图像绘制在后台完成，阅读界面只取已完成的图像；同时预排下一章。章节未准备完成时保留旧页并显示准备提示，禁用翻页，防止把旧章节的页码或延迟回调写入新章节。换章不再等待字号滑块的 120 ms 合并延时。原生逐页图像/分页回归已加入 Actions 测试，实际流畅度和用户反馈章节的完整性仍需编译后在设备上复验。

设置采用独立实色底部面板；收起状态下，在面板任意区域向上拖动即可展开，不必瞄准顶部横条。展开后可从标题、空白或列表区域下拉收起；如果列表已经滚动，先向下滑回列表顶部，同一手势继续下拉即可带动面板。向上滑动展开后的列表仍正常滚动选项。横向调整滑块不触发面板拖动。面板高度变化不改变正文的排版尺寸，也不添加随高度变化的背景变暗效果。字号/行距拖动会合并连续变化，停止调整约 120 ms 后应用排版。

### 图片背景与搜索历史

- 阅读菜单 → 设置，最上方即为「背景」分区。「选择/更换背景图」和红色「删除背景图」并排显示，不再藏在预览图下方；无图时删除按钮禁用但仍可见。支持 10%–100% 图片浓度调整。背景用于分页和滚动模式，设置面板仍使用实色以保证选项可读。
- 图片最大 32 MB，导入时按方向校正并缩小到最长边 2048 像素，转换为应用内部 PNG；重启后恢复，移除后回到所选主题。不会更改原照片，也不随翻页重复解码或重新分页。
- 「找书」保存最近 30 条非空搜索，自动去重并将再次搜索的词置顶。点击历史词直接搜索，左滑删除单条，「清空」经确认后删除全部，重启后保留。

## iPhone 本地文件导入

1. 「书源 → 从 JSON / XBS 文件导入 → 选择 JSON / XBS 文件」，使用系统文档选择器复制导入，文件不需要提供编辑权限。
2. 也可在「文件」App 长按 JSON/XBS → 分享 → 映夏阅读，触发导入。请先让 iCloud/第三方提供器完成下载。

保留已可正常使用的 UIKit 文档选择器（复制模式）及系统打开文件入口。1.3.0 按要求移除文件夹导入入口和应用内文件夹浏览，不改变 JSON/XBS 文件解析逻辑。

## 香色书源兼容范围

可直接导入附件形状的 `{"alias":{"sourceName":...,"sourceUrl":...,"searchBook":...}}` JSON，也可解码该 JSON 的标准 XXTEA XBS 容器。规则保留原文，通过独立香色引擎执行；内部书源标识与 Legado 隔离。

当前支持 DOM / html、XPath（含列表子项、属性和联合选择）、`@js:` 请求及字段处理、`%@result`、`config.host` / `params.keyWord` / `queryInfo`、POST/httpParams/httpHeaders、UTF-8/GBK 响应、正文与目录 `nextPageUrl` 分页、循环与跨章保护。复杂 JS parser、JSONPath、nativeTool、香色 WebView/嗅探、响应解密、非空 validConfig、GBK POST 参数编码尚不支持，会显示错误；不声称完整复刻 StandarReader。

附件 `suduguu.source.json` 未修改，作为开发测试样本保存在 `Tests/Fixtures/`，不自动安装进 App。2026-11-23 对原始规则的独立联网验证取得 10 条搜索结果、999 条目录以及首章 4 页正文。网站实际还有下一页目录，但附件 `chapterList` 没有 `nextPageUrl`，因此仅返回第一页目录；简介 XPath 也未匹配当前页面。以上属于附件规则限制，详见 `Docs/xiangse-live.json`，不代表 iOS 或香色官方 App 已验收。

## 导入和切换字体

阅读时点击屏幕中间 →「设置」→「导入与更换字体」→「导入 TTF / OTF 字体」。导入后立即使用该字体，支持预览、系统字体切换、左滑删除；字体复制到应用内部并在重启时重新注册。每个文件最大 32 MB，文件内容和内部字体名均会验证，重复文件不会重复添加。1.2.1 按规范化文件路径比较，防止导入文件与目录枚举 URL 表示不同而误判为重名。内部名称相同的再次导入会启用已保存的字体；替换同名的不同版本时，先左滑删除旧字体，再导入新文件。无法注册的旧文件会列在「需要修复的字体」中，支持直接删除，不再隐藏到列表之外。

附件「笔落纸端勾勒回忆.ttf」已用 FontTools 检查，内部 PostScript 名为 `BiLZDGLHYSS`，包含 10575 个映射字符。App 的字体列表使用字体内部名称，不一定等于文件名。用户字体没有内置到源码或安装包；请在 App 中导入原文件。CoreText 真机显示效果仍需 iOS 验证。

这个移植对应上游的在线小说功能，不是 EPUB/PDF 阅读器。不附带第三方书源或书籍。当前界面不包含探索分类和书源登录表单；需要交互登录的书源暂不适用。已保留通用规则引擎及 WebKit 页面解析能力，网站规则失效、验证码或网络错误仍可能导致读取失败。

## GitHub Actions 打包

将**本目录内的文件**作为 GitHub 仓库根目录上传，注意包含 `.github` 隐藏目录。无需上传外层工作区或原仓库。

1. 打开 GitHub 仓库 → Actions → **Build iOS Reader** → Run workflow。
2. 工作流在 macOS 上安装 XcodeGen、生成 Xcode 项目、执行 iOS 模拟器测试、构建 Release 真机应用并封装 IPA。
3. 成功后在该次运行的 Artifacts 下载 **YingxiaReader-iOS-unsigned**，解压得到 `YingxiaReader-unsigned.ipa`。

工作流使用 `macos-26-intel` 托管运行器，避开本次 `macos-26` ARM 运行器容量不足的问题。若停在 `Waiting for a runner to pick up this job`，说明还未开始执行编译步骤；更新工作流后请取消旧排队任务，并重新点 **Run workflow**，不要重跑引用旧提交的任务。更换运行器仍可能排队，不保证立即启动。

默认不需要证书 Secrets，产物**未签名**。IPA 需要使用你自己的 Apple 账号和签名工具重签后安装，无法直接点击安装，也不能直接上传 App Store/TestFlight。此工作流不会自动发布 Release。

应用显示名为「映夏阅读」，版本 1.3.2 / build 7；保留原 Bundle ID、Xcode scheme 和英文产物名称，便于覆盖升级并保留书架、字体及阅读设置。

## 在 Mac 上构建 / 签名

安装 Xcode（支持 Swift 6 / iOS 17+ SDK）及 XcodeGen 后运行：

```sh
brew install xcodegen
python3 scripts/check-project.py
xcodegen generate
open YingxiaReader.xcodeproj
```

选择 `YingxiaReader` scheme。若通过 Xcode 安装真机，在 `project.yml` 将 `CODE_SIGNING_ALLOWED` 改为 `YES`，使用自己的唯一 Bundle ID，重新生成项目，并在 Signing & Capabilities 中选择自己的 Team / 自动签名。不要提交证书或密码。
